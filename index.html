🎃 Pumpkin Domain

Learn this first, then finish your pumpkin. It takes about 2 minutes!

🎃 What is DOMAIN?

Domain = all the x-values a graph uses.

Read it from left ➜ right along the x-axis.

y = 1 { −3 ≤ x ≤ −1 }

This line starts at x = −3 and stops at x = −1.
So its domain is −3 ≤ x ≤ −1.

👻 What is RANGE?

Range = all the y-values a graph uses.

Read it from bottom ⬆ top along the y-axis.

x = −3 { 1 ≤ y ≤ 2.4 }

This line starts at y = 1 and stops at y = 2.4.
So its range is 1 ≤ y ≤ 2.4.

🔪 Why do we need it?

A line like y = 1 goes on FOREVER in both directions. 😱

Domain and range work like a pumpkin-carving stencil ✂️: they tell the graph where to START and where to STOP.

In Desmos, you type them in curly brackets { } after the equation. Game designers and animators use the same idea to draw shapes. In real life they set limits too: you can't buy −3 candy bars, and a phone battery only goes from 0% to 100%.

2. Which one limits the RANGE (the y-values)?
